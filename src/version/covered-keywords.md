# Covered keywords file

## What covered keywords represent

The covered-keywords file (`data/oasdiff-<version>.covered-keywords.json`) enumerates every JSON-Schema/OpenAPI keyword that oasdiff's own rule catalogue ever judges at all.

It is generated by `scripts/generate-oasdiff-covered-keywords.mjs` from the same rule catalogue that `classification-map.ts` loads. Both sources come from the same committed rule file (`data/oasdiff-<version>.checks.json`).

## How plan.ts uses this for structural fallback

`plan.ts`'s structural fallback uses this set the opposite way from the classification map: a real structural difference at a keyword _absent_ from this set is one oasdiff has no rule for at all, so oasdiff's silence about it carries no information. Speckify forces major version bumps rather than trust that silence, avoiding under-bumping.

## Version coupling

The covered-keywords file is pinned to a specific oasdiff version. `loadCoveredKeywords()` validates that the file's version matches Speckify's pinned oasdiff version; if versions diverge, the covered-keywords file must be regenerated using `scripts/generate-oasdiff-covered-keywords.mjs`.
